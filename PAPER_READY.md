```
All architectures were trained with identical hyperparameters for fair comparison:
- Batch size: 16
- Learning rate: 3e-4
- Epochs: 200 (with early stopping patience 30)
- Optimization: Adam (weight decay 1e-4, gradient clip 1.0)
- Evaluation metric: AUPR (Precision-Recall AUC) for model selection

3 random seeds (15 evaluations each). Independent datasets (Human, BIOSNAP, 
C. elegans, BindingDB) used 80-10-10 train-val-test split with 5 random seeds 
(5 evaluations each). Fragment embeddings were set to 128 dimensions with 
automatic 128→64 projection in Mamba SSM layers.
```

## Key Technical Fixes Documented

All major technical fixes are documented in code with references:

1. **Sigmoid Numerical Stability** (trainer.py:192-197)
   - Changed: `1.0 / (1.0 + np.exp(-predictions))` → `scipy.special.expit()`
   - Reason: Prevents overflow for |predictions| > 700

2. **Metric Key Consistency** (train_cv.py:242-243)
   - Changed: `metrics['pr_auc']` → `metrics['aupr']`
   - Reason: Match actual Metrics.compute_metrics() output keys

3. **NaN Checkpoint Prevention** (trainer.py:330-332)
   - Added: `if np.isnan(current_aupr): current_aupr = 0.0`
   - Reason: NaN > X always returns False, preventing checkpoint saving

4. **Confusion Matrix Edge Cases** (metrics.py:113-125)
   - Added: Shape checking and fallback handling
   - Reason: cm.ravel() fails when matrix not 2x2 (single-class data)

5. **Double-Sigmoid Bug Fix** (train_cv.py:234-235)
   - Removed: Redundant expit() after trainer.predict()
   - Reason: trainer.predict() already applies torch.sigmoid()
